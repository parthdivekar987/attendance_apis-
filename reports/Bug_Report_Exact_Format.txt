BUG-HCM-ATT-001: Unhandled 500 Internal Server Error & JPA Entity Leak in Status Threshold Master
--------------------------------------------------------------------------------
Method: GET
URL: https://uatmcdphcmplatform.omfysgroup.com/api/attendance/status-threshold/getAll?page=0&size=10&sort=non_existent_column,desc
UI Navigation Path: Attendance Management -> Status Threshold -> Threshold List Grid

Technical & Business Root Cause Explanation:
Passing an unmapped sort field to the `sort` query parameter triggers Spring Data JPA's `PropertyReferenceException`. The exception bubbles up unhandled, returning HTTP 500 and exposing the internal JPA entity class `AttendanceStatusThresholdMaster` to the client.

Request Parameters:
?page=0&size=10&sort=non_existent_column,desc

Actual Response:
Status: 500 Internal Server Error
Body:
{
  "status": "error",
  "errorCode": "500",
  "message": "No property 'non' found for type 'AttendanceStatusThresholdMaster'",
  "timestamp": "17-Aug-2026 T14:15:30"
}

Expected Response:
Status: 400 Bad Request
Body:
{
  "status": "error",
  "errorCode": "INVALID_SORT_PROPERTY",
  "message": "Invalid sort property 'non_existent_column'. Allowed fields: ['thresholdId', 'thresholdCode', 'thresholdName', 'templateMode', 'effectiveFrom', 'effectiveTo']",
  "timestamp": "17-Aug-2026 T14:15:30"
}

BUG-HCM-ATT-002: Accepted Quotes-Only Threshold Name in Status Threshold Master
--------------------------------------------------------------------------------

URL: https://uatmcdphcmplatform.omfysgroup.com/api/attendance/status-threshold/create
UI Navigation Path: Attendance Management -> Status Threshold -> Create Template -> Threshold Name Input

Technical & Business Root Cause Explanation:
The backend validation fails to sanitize or trim escaped quote characters (`""""`). As a result, meaningless strings consisting solely of quotation marks bypass validation and create active threshold records in the database.

  "effectiveTo": "2030-12-31",
  "isDefault": "N",
  "isActive": "Y",
  "templateStatus": "DRAFT",
  "remarks": "Fuzzing test",
  "assignments": [
    {
      "employeeId": 34,
      "effectiveFrom": "2030-01-01",
      "effectiveTo": "2030-12-31",
      "isActive": "Y"
    }
  ]
}

Actual Response:
Status: 201 Created
Body:
{
  "status": "success",
  "message": "Status Threshold created successfully",
  "data": { "thresholdId": 82 }
}

Expected Response:
Status: 400 Bad Request
Body:
{
  "status": "error",
  "errorCode": "VALIDATION_ERROR",
  "message": "Threshold Name must contain valid alphanumeric characters and cannot consist solely of punctuation marks or quotes"
}
