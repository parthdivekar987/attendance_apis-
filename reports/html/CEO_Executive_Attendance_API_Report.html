ðŸš¨ Critical Business & Operational Defects

BUG-HCM-ATT-001 Critical Security
Unhandled 500 Error & JPA Domain Entity Leak on Invalid Sort
Business Impact: Exposes internal database architecture (AttendanceStatusThresholdMaster) to potential attackers and crashes the API on invalid query parameters.
Endpoint Specification:
GET /api/attendance/status-threshold/getAll?sort=invalidSort,asc
Developer Action Required:
Implement property whitelist validation in Controller.
BUG-HCM-ATT-002 & 006 Critical Data Integrity
Quotes-Only Policy Name Validation Bypass (HTTP 201 Created)
Business Impact: Allows creation of blank/invisible policy names ("""") in the database, resulting in blank UI cards and broken policy assignment dropdowns.
Endpoint Specification:
POST /api/attendance/status-threshold/create (Body: { thresholdName: '""""' })
Developer Action Required:
Add @Pattern regex constraint rejecting quote-only strings.
BUG-HCM-ATT-003 Critical Scheduling
Inverted Date Order Accepted on Week-Off Assignment
Business Impact: Backend accepts effectiveTo dates earlier than effectiveFrom (e.g. 30-Aug to 01-Aug), corrupting scheduling calculations.
Endpoint Specification:
POST /api/attendance/week-offs/assign
Developer Action Required:
Add @AssertTrue validation verifying effectiveTo >= effectiveFrom.
BUG-HCM-ATT-008 Critical Payroll Risk
Status Deactivation Cascade Desynchronization (Parent 'N' leaves Child 'Y')
Business Impact: When an HR admin deactivates a late penalty policy, assigned employees continue receiving penalties because child records remain active in DB.
Endpoint Specification:
PATCH /api/attendance/late-early-policies/status/toggle
Developer Action Required:
Execute cascading transactional update on child assignment rows.
BUG-HCM-ATT-009 Critical UI Blocker
Inactive Leave Type 7 (OD) Accepted - UI Edit Form Permanent Lock
Business Impact: Policy can be linked to deactivated leave types. When an admin attempts to edit the policy later, the UI form throws an exception and locks.
Endpoint Specification:
POST /api/attendance/late-early-policies/create
Developer Action Required:
Validate Foreign Key isActive = 'Y' before linking.
BUG-HCM-ATT-012 Critical Concurrency
TOCTOU Race Condition Vulnerability Allows Duplicate Policy Names
Business Impact: Simultaneous clicks create duplicate policies with identical names in the DB because uniqueness check is in application memory.
Endpoint Specification:
POST /api/attendancepolicy (10 Parallel Threads)
Developer Action Required:
Add database unique constraint: ALTER TABLE attendance_policy ADD CONSTRAINT uk_policy UNIQUE (policy_name).
